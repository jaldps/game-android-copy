# Bowbrawl — asset credits

All visuals and audio are original and generated at runtime; no external models, textures or sound files.

- **Characters, bows, arrows, props, terrain, skies:** procedural geometry and shaders in `characters/`, `arrows/`, `maps/`, `core/`.
- **Sound effects and music:** synthesized with the Web Audio API (`audio/`).
- **Typography:** the repository's shared font stylesheet `web/shared/fonts.css`.
- **three.js** (MIT License), vendored in `web/lib/`.
